# Excel Analytics Projects

This repository collects Excel workbooks and supporting internship/visualization materials. The primary portfolio workbook is the car-sales cleaning and dashboard project.

## Car-sales analysis workflow

The workbook is organized around a source sheet, supporting analysis sheets, and a dashboard:

1. **Prepare the source data** in `Car_sales`.
2. **Explore and summarize** the data in `Engine size` and `Unit Sales`.
3. **Build visual views** on `Line Chart` and `Bar Chart`.
4. **Review the dashboard** on `Car_sales_Dashboard`.

The workbook contains six sheets, four pivot tables, and eight charts. The portfolio description reports that the analysis covers more than $2 million in sales and uses pivot tables, slicers, and dynamic charts. Open the workbook to inspect the interactive controls and calculations.
